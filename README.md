# gadabout-data

Venue data for the Gadabout app (Greater London), refreshed nightly from the Geofabrik
OpenStreetMap extract and served with GitHub Pages. The app checks `index.json` on open
and downloads newer tiles (`t_<lat10>_<lon10>.json`) when the `updated` date changes.
